# Supreme Schemes

Crusader Kings III intrigue mod. Version **0.4.0**. Supported game version 1.20.*.

Embrace the Supreme Schemer trait for days-scale plots, near-guaranteed success at High intensity, plus hostile schemes to steal artifacts and titles through intrigue (not war).

## 0.4.0 — Next-iter wave

- **Machinations (Verb Pack 2):** Abduct, Force Contract, Smear schemes (days-scale; High can’t-fail).
- **Hook Board:** Spend strong hooks from the manage hub (rewrite contract, force vote, buy SU pact approval, silence factions). Influence alternate cost when RtP/TGP + influence government.
- **Auto Hook Scopes:** Opt-in silent strong hooks for new courtiers, newly landed barons, and prisoners (master Auto Strong Hooks still required). Hook All Courtiers / Hook All Prisoners decisions.

## Earlier

- **0.3.0:** Auto Strong Hooks on new direct vassals + Hook All Vassals.
- **0.2.0:** Higher title steal cap + Discover Secrets.
- **0.1.x:** Demand Strong Hook, hook spend / Fabricate Hook CD clear, core turbo + steal schemes.
